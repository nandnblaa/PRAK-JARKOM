### Deskripsi
Praktikum ini membahas konfigurasi dasar MikroTik, mulai dari pengenalan interface, konfigurasi IP Address, pengaturan gateway, DNS, serta pengujian konektivitas jaringan.

Konfigurasi dilakukan menggunakan MikroTik RouterOS melalui aplikasi Winbox untuk mengatur perangkat agar dapat terhubung ke jaringan dan melakukan komunikasi dengan perangkat lain.

### Pengujian
Pengujian konektivitas dilakukan menggunakan perintah `ping` untuk memastikan PC dapat terhubung ke interface MikroTik. Pengujian juga dapat dilakukan untuk memeriksa koneksi ke gateway dan jaringan luar apabila konfigurasi internet digunakan.
